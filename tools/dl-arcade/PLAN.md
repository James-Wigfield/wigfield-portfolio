## The frozen game contract

```js
// games/<gameId>/index.js
export default {
  id: 'param-sniper',
  title: 'Param Sniper',
  lectures: [1, 2, 3, 4, 5, 6, 8],        // 6 = Lectures 6–7
  concepts: ['params.dense', …],          // ids from core/concepts.js
  blurb: 'One line.',
  load: () => import('./ParamSniper.jsx'), // lazy
};
// The component receives { seed, level, mode: 'free'|'mix'|'exam', durationMs, onRoundEnd, onExit }
// and calls onRoundEnd({ score, maxScore, outcomes: [{ concept, correct, src }] }) exactly once.
```

Kit support every game is expected to use (so the bot, results and why-cards are uniform):

```js
const round = useRound({ seed, level, mode, durationMs, onRoundEnd, items /* or next() */, gameId });
// round.current  → the item on show: { id, concept, src, prompt, answer, kind: 'number'|'choice'|'custom', choices?, why }
// round.submit(value)   → grades (item.check ?? equality), records the outcome, advances; returns { correct, item }
// round.skip()          → wrong, advances
// round.finish()        → ends early; onRoundEnd fires once
// round.state           → 'intro' | 'play' | 'results'
// round.score, round.combo, round.streak, round.msLeft, round.index, round.total, round.mistakes
// In DEV the kit registers window.__dla = { gameId, round: { current, submit, skip, finish, state } } for the bot.
```

Items are generated by pure functions in `maths/` from `content/` facts, seeded by `rng(seed)`.

## Accuracy protocol (short form; the master brief is binding)
- Sources: lecture PDFs, then markdown transcripts (+ Quirks). Nothing else.
- No facts in components: content/ + maths/ only, every item with `src: { lecture, slides: [] }`, `beyond: true` when not in the slides.
- Slide anchors are test cases; `check-maths.mjs` must match `keras-truth.json` 100 %.
- One fresh accuracy checker per game; zero WRONG before a game is accepted. Then a whole-arcade re-audit.
