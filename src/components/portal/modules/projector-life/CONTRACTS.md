The interfaces every part of `projector-life/` agrees on. The brief is
`Documents/temp/prompt-dumping/build_projector_life_visualiser.md` (in the main
checkout). Change a contract only through the lead; additions are fine if they
are backwards compatible and written down here.

Stack: **plain three.js** (`three@0.185`, `three/addons/...`), one `WebGLRenderer`
owned by `engine/Stage.js`. No R3F. No new npm dependencies. CSS prefix
**`pjl-`** (unused elsewhere in `src/`). ES modules, lint with
`npx eslint src/components/portal/modules/projector-life tools/projector-life`.

## §2 The room model (patches)

`room/roomModel.js` is the pure-maths reference (Node-safe, no three.js).
`buildPatches({ apex, loft, loftPolygon })` returns `Patch[]`:

```js
Patch = {
  id: 'wall-N'…'wall-NW' | 'roof-N'…'roof-NW' | 'floor' | 'loft',
  kind: 'wall' | 'roof' | 'floor' | 'loft',   // geometric family
  flat: 'N'…'NW' | null,  k: 0…7 (walls/roofs),
  type: 'floor' | 'wall' | 'ceiling',          // habitat; = typeAuto unless overridden
  typeAuto,                                    // from the normal: n.y > .5 floor, < −.5 ceiling
  origin: [x,y,z],  u: [x,y,z],  v: [x,y,z],   // local (x,y) → world = origin + x·u + y·v
  normal: [x,y,z],                             // INWARD (faces the room) = u × v
  polygon: [[x,y],…],                          // local metres, CCW, inside the +x/+y quadrant
  width, height,                               // local bounding box [0,width]×[0,height]
  area,                                        // m²
  corners3d: [[x,y,z],…], centroid3d,
  masks: [{ id, kind: 'door'|'window'|'loft'|'furniture', polygon: [[x,y],…] }],
  seams: [{ edge, to, toEdge, length, M: [a,b,c,d,tx,ty] }],
  gravity: { gt: [gx, gy], gn },               // unit world gravity in local terms
  pitchDeg (roof facets only),
}
```

* **Local frames.** Walls: origin = left corner at floor level, x along the
  flat to the right (seen from inside), **y up**; edges 0 bottom, 1 right,
  2 top (eave), 3 left. Roof facets: origin = left eave corner, x along the
  eave, **y up-slope** to the apex (polygon `[[0,0],[s,0],[s/2,slant]]`);
  edges 0 eave, 1 right hip, 2 left hip. Floor and loft: x = east, y = north,
  origin at the SW corner of the bounding square (world `(0, y, 4.36)`).
* **Seams.** Edge i runs polygon[i] → polygon[i+1]. `seam.M` maps *this*
  patch's local coords to `to`'s local coords as the **unfolding isometry**
  (rotation + translation): a point just past the edge lands just inside the
  neighbour; directions rotate with `mapDir(M, dx, dy)`; headings add
  `mapAngle(M)`. 64 seams at any apex (walls 4 each, facets 3, floor 8); the
  loft has none (`noSeams`) — creatures reach it by falling.
* **Gravity.** World g = (0, −1, 0), unit; sims multiply by their own
  strength. `gt` = along-surface "down" in local axes (walls `[0,−1]`, facets
  `[0, −sin pitch]`, floor `[0,0]`). `gn` = −g·n: **+ presses in** (floor +1),
  0 on walls, **− peels off** (facet −cos pitch). Steeper roof ⇒ more
  downslope, less pull-off.
* **Masks** live in patch-local coords. Mask polygons are where the surface
  is blocked (door leaf, window glass, the loft deck/balustrade against the
  wall, furniture standing against a wall or on the floor). Whether a mask is
  *active* is a param (`map.mask.*`); the patch carries all of them. Mask ids:
  `door`, `window`, `loft`, `loft-post`, or the furniture object name
  (`armchair`, `barrel`, …). Loft masks exist only while the loft is shown,
  furniture masks only while furniture is shown (so `room.loft` /
  `room.furniture` change the patch list: 18 ↔ 17 patches, masks change).
  `buildPatches()` with no options returns the measured loft and masks.
* **Rebuild.** Every patch is rebuilt when `room.apex` changes (ids stay the
  same). Consumers must treat the patch array as immutable and replace on
  `setPatches()`.
* **Texture convention** (life → projection): a patch's sim buffer is
  `w × h` cells at `ppm` cells/metre, **row j covers local y ∈ [j/ppm, (j+1)/ppm)**,
  column i covers x ∈ [i/ppm, …). Uploaded as a `DataTexture` with
  `flipY = false`, so `uv = (x / (w/ppm), y / (h/ppm))`. Cells outside the
  polygon (or under an active mask) are black.

## §3 Room runtime — `room/index.js` → `loadRoom({ renderer, values })`

Async; resolves to:

```js
{
  root: THREE.Group,          // GLB + new roof + hip battens + aids; the Stage adds it to the scene
  patches: Patch[],           // getter; current list (rebuilt on apex change)
  landing(x, z, fromY) → { y, patchId, local: [x,y], surface: 'floor'|'loft'|'furniture' },
                              // where a body dropped at (x, fromY, z) comes to rest: highest
                              // upward-facing surface below fromY (floor, loft deck, furniture
                              // tops). Pure data (a heightfield built once at load) so the life
                              // host can call it every tick. patchId is 'floor'/'loft' or null on furniture.
  views: { cutaway, door, armchair, loft, plan }   // { position:[x,y,z], target:[x,y,z], fov }
  surfaceMeshes: THREE.Mesh[],  // every mesh that should RECEIVE projector light (walls, floor,
                                // furniture, loft, new roof) — projection patches their materials
  occluders: THREE.Object3D[],  // what blocks projector light (same set minus glass)
  setParams(values, changedKeys) → { patchesChanged: boolean },
                                // room.apex (rebuild roof geometry IN PLACE — keep material
                                // instances), room.furniture, room.loft, room.cutaway,
                                // room.oldRoof, aid.gravity / aid.seams / aid.labels
  update(camera, dtMs),         // per frame: cutaway fades (near walls + near roof facets)
  pick(raycaster) → { patchId, local:[x,y], world:[x,y,z] } | null,   // first hit on a patch
  dispose(),
  // additions (room agent)
  fadedLayer: 7,                // fully faded cutaway meshes move to this layer; the cutaway NEVER
                                // sets .visible — .visible means "physically present"
  measured,                     // room/measured.js (deck, door, window, masks)
  roofApex,                     // getter: apex the roof patches use (room.apex, or 2.738 with room.oldRoof)
}
```

* `views.cutaway` and `views.plan` are **getters** (they depend on the pitch
  and the canvas aspect); door / armchair / loft are fixed.
* Every surface mesh carries `userData.pjl = { part, patchId, albedo }` —
  part ∈ `wall | floor | loft | furniture | roof | roofTrim | roofTop | oldRoof | glass`;
  `albedo` = paint colour (`#cfdad2` walls, `#5f4b3c` floor, `#efede8` roof)
  or null (use the bake). Walls are split per flat (8 meshes), so a wall mesh
  maps 1:1 to its patch.

Rules: never edit the GLB or `src/memory-rooms/`; copy what you need from
`RoomViewer.js` / `bakedMaterials.js` / `dollhouse.js`. Materials stay
`MeshBasicMaterial` (projection patches them with `onBeforeCompile`), and the
room must **not swap material instances after load** (fades change opacity on
the instances they cloned at load). `room.ambient` is NOT the room's job — the
projection shader darkens the bake.

## §4 Life host — `life/index.js` → `createLifeHost({ patches, landing, values })`

CPU only, **no three.js and no DOM in the core** (so `tools/projector-life/sim-check.mjs`
runs it in Node). Returns:

```js
{
  setPatches(patches),          // apex changed: resample / rebuild grids, keep populations
  setParams(values, changedKeys),
  step(dtSeconds),              // real time; the host runs fixed ticks inside its own budget
  surfaces() → Map<patchId, { w, h, ppm, data: Uint8Array /* RGBA, §2 convention */, version }>,
  frame() → { w, h, data, version } | null,   // one flat rectangle of content for map.mode = 'raw'
  airborne() → [{ x, y, z, r, color:[r,g,b] }], // world-space bodies in flight (not projectable)
  seed(patchId, x, y),          // local metres
  reseed(), clear(),
  stats() → {
    simMs, tick,
    populations: { floor, wall, ceiling },          // agents/creatures alive per habitat
    creatures: { alive, born, died, fell, landed, onAir },
    histograms: { feet|grip|mass|swing|flight: { edges:number[], floor:number[], wall:number[], ceiling:number[] } },
  },
  dispose(),
}
```

* Copies of `public/artificial-life/src/{systems,lib}/*.js` live under
  `life/` with a provenance header (source path, what changed). Never edit
  `public/artificial-life/`.
* Background is **pure black** (`0xff000000`), palettes brighter for
  projection, chosen by `life.*Palette`.
* Which system runs on a patch: `region.<id>.system` if not `'auto'`, else
  `life.sys.<type>` where type = `region.<id>.type` if not `'auto'` else
  `patch.typeAuto`. `region.<id>.on === false` → that patch is black.
* Masks: active masks (`map.mask.*`) are black and are walls for agents.
* Budget: one global budget split by patch area; default preset must cost
  ≲ 6 ms/frame on this PC. Pause is the Stage's job (it stops calling step).

## §5 Projection — `projection/index.js` → `createProjection({ renderer, scene, room, life, values })`

```js
{
  attach(room),                 // patch room.surfaceMeshes' materials (onBeforeCompile, shared
                                // uniforms, customProgramCacheKey); build the content scene
  setPatches(patches),          // apex changed
  setParams(values, changedKeys),
  update(dt),                   // upload changed life buffers; re-render projector outputs every
                                // frame, projector depth maps only when projectors/room change
  beforeRender(camera),         // per-frame uniforms
  outputs() → [{ index, texture, aspect }],   // what each active projector emits (pre-warped)
  projectorView(i) → { position, target, fov, up? },   // for the "Projector's view" camera
  coverage() → { floor, wall, ceiling, total, perPatch: { [id]: 0..1 }, byCount: [f0,f1,f2,f3] } | null,
                                // area fractions, occlusion-aware, recomputed when projectors/room change
  drawNet(canvas2d),            // unfolded-room inset: patches flat as a net, sims running, seams drawn
  dispose(),
}
```

* The projection system adds its own helpers (frustums, projector bodies) to
  `scene` and removes them on dispose.
* Light model per fragment: `out = baked·ambient + albedo · Σ_projectors light`,
  `albedo` derived from the bake (walls ≈ `#cfdad2`), `light = output(uv)·brightness·falloff(d, cosθ)
  + black level` inside the frustum and not occluded (shadow map). Coverage view
  and pixel-size view are shader modes.
* Mapped mode: each projector's output = the patches' life textures rendered
  from the projector's camera (masks / furniture black when their mask is on).
  Raw mode: output = `life.frame()` stretched over the whole frame.

## §6 Stage API (what the UI calls) — `engine/Stage.js`

```js
const { createStage } = await import('./engine/Stage.js');   // keep it a dynamic import
const stage = await createStage(hostDiv, { values, view: 'cutaway' });
stage.set({ 'room.apex': 3.6 });          // partial update; coerced by params.js
stage.replace(preset.values);              // defaults + overrides (+ reseed)
stage.setView('door');                     // smooth unless reduced motion
stage.play(); stage.pause(); stage.step(); stage.reseed(); stage.clear(); stage.reset();
stage.savePNG();
stage.setNetCanvas(canvasEl);              // DOM canvas for the unfolded-room inset
stage.insetRect();                         // projector-output inset rects (CSS px in the stage)
stage.getValues(); stage.getPatches();
const off = stage.subscribe((s) => …);     // ~4 Hz: { ready, playing, view, fps, frameMs, pitchDeg,
                                           //          life, coverage, insets, lastSeed }
stage.dispose();                           // full teardown incl. forceContextLoss
```

Clicking (not dragging) a surface seeds life there.

## §7 Params and presets

`params.js` is the single source of truth (keys are the contract; see the file
header). `presets.js` exports
`PRESETS = [{ id, name, blurb, camera, values: { key: value } }]` — values are
partial overrides of `defaults()`; the first preset is the default scene.
